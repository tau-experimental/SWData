# ТЕХНИЧЕСКИЙ ПАСПОРТ ПРОЕКТА: КВ-МОДЕМ OFDM/DPSK ДЛЯ CH32V307

## 1. Спецификация Физического Уровня (Layer 1)
*   **Частота дискретизации (Fs):** 8000 Гц.
*   **Окно ДПФ (N_SAMPLES):** 160 сэмплов (20 мс).
*   **Защитный интервал (CP_SAMPLES):** 32 сэмпла (4 мс, циклический префикс).
*   **Полный кадр символа:** 192 сэмпла.
*   **Формат сигнала:** Комплексный квадратурный IQ (Стерео: Левый = I, Правый = Q).
*   **Сетка частот данных:** 4 тона — 1000, 1200, 1400, 1600 Гц. 
*   **Модуляция:** Дифференциальная квадратурная фазовая манипуляция направления (Шаг фазы в DDS: Бит 0 = -90° (-64 отсчета таблицы), Бит 1 = +90° (+64 отсчета таблицы)).

## 2. Архитектура Программных Модулей (ANSI C)

### Передатчик (tx.c / tx.h)
*   Реализован на базе **целочисленного табличного DDS** (Размер таблицы синуса = 256 элементов float).
*   Используются 32-битные непрерывные аккумуляторы фазы (`dds_phase_acc`). Фаза тонов плавно перетекает через границы символов, обеспечивая идеальную непрерывность спектра.
*   Функция `tx_step_phase(uint8_t nibble)` вызывается СТРОГО один раз перед стартом нового кадра и инкрементирует статические сдвиги `dds_phase_shifts` на ±64 отсчета таблицы.

### Приёмник (rx.c / rx.h)
*   **Память:** Линейный плоский буфер `data_buffer[192]` для накопления текущего кадра (никаких круговых индексов на этапе ДПФ).
*   **Синхронизация времени:** Непрерывно бегущий счётчик `rx_global_timer`. Опорный генератор ДПФ привязан к абсолютному времени канала для исключения межсимвольного набега фаз на дробных периодах частот.
*   **Решающее правило:** Квадратурный дискриминатор. Бит определяется строго по знаку мнимой части комплексного скалярного произведения текущего и предыдущего символов (`dot_product_im > 0.0f -> Бит 1`).

## 3. Текущее Состояние и Зафиксированные Баги
1.  **Лабораторный тест DPSK (Когерентный бенчмарк):** Пройден на 100% (6 из 6 попаданий, фраза "HELLO RISCV" успешно декодируется в идеальных условиях).
2.  **Проблема Потоковой Синхронизации (Squelch / Детектор):** Энергетический сквелч Шмидла-Кокса отключен из-за ложных срабатываний на данных и ослепления в кристальной тишине.
3.  **Текущий баг Интегрального Дискриминатора Скачков:** Посэмплный скользящий детектор переключений на базе двух 16-сэмпловых окон ДПФ (Окно А и Окно Б) ложно срабатывает на отметке **983** вместо реального начала сигнала на **299** сэмпле. Гетеродинирование `calc_sliding_dft` по локальному времени `t_local [0..15]` уничтожает КВ-фазу расстройки канала, заставляя триггер промахиваться.

## 4. Задачи для Новой Сессии
1.  Исправить тригонометрию скользящих 16-сэмпловых ДПФ-окон в `RX_STATE_SEARCH`, чтобы точка `sync_absolute_tick` безошибочно защёлкивалась на **299-м сэмпле** (на самом первом фронте прилета преамбулы `0xA5`) как в шуме, так и в кристальной тишине.
2.  Восстановить прецизионную калибровку КВ-дрейфа частоты до точных **-22.40 Гц** на этапе `RX_STATE_PREAMBLE_CALIBRATE`.
3.  Разработать защитный Hold-детектор (Таймер обрыва связи) для автоматического сброса FSM в режим `SEARCH`, если преамбула ушла, а боевые данные не начались.
